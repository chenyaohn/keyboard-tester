# 键盘检测器

这是一个原生 Windows 键盘检测工具，用于检查按键能否正常发出“按下”和“松开”事件，并提示疑似快速抖动或长时间未松开的情况。

## 使用

1. 双击 `release\KeyboardTester.exe`。
2. 点击程序窗口，让窗口标题栏处于激活状态。
3. 按实际键盘逐个按下并松开按键。
4. 蓝色表示按下中，绿色圆点表示已经收到松开，橙色表示需要留意。
5. 检测结束后点击“导出报告”，可以得到逐键结果和未测试的按键清单。

程序默认显示 104 键全尺寸布局。右上角可以切换为 87 键（无数字区）布局。

## 判定说明

- 未测试的按键不等于故障，需要实际按一遍再根据结果判断。
- 按住一个键时，系统产生自动重复是正常现象，不记为故障。
- 松开后 45 ms 内再次出现按下，并且连续发生时，程序会标记“疑似快速抖动”，建议复测。
- 按键按下超过 5 秒仍未收到松开，程序会临时提示。
- 虚拟键盘只显示检测结果，鼠标点击键帽不会计入测试。
- 检测期间会临时拦截 Win、Alt、Print Screen 等可能打断检测的系统键。要退出程序，请点击右上角关闭按钮。
- Windows 安全注意序列 `Ctrl+Alt+Delete` 无法被普通程序拦截，因此不建议用它来测试按键。
- 某些带宏、多媒体或特殊驱动的键盘会把输入模拟成软件事件；程序会忽略这些模拟输入，以免误判。

## 重新构建

在 PowerShell 中运行：

```powershell
.\build.ps1
```

构建脚本使用 Windows 自带的 .NET Framework 编译器，不需要额外安装 SDK。构建完成会自动运行内置自检，结果写入 `self-test-result.txt`。

## 系统要求

- Windows 7 及以上
- .NET Framework 4.x（Windows 10/11 默认已安装）
